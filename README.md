# आँगन — Aangan Radio

Open `index.html` on a normal web host (Vercel/Netlify/GitHub Pages) for the most reliable YouTube and weather behavior.

## Music
Uses the official YouTube IFrame Player API and the supplied 90s Hindi playlist. Browsers require a user interaction before audible autoplay, so the first click on ▶ starts the radio.

## Images
The 9 supplied Aangan images are included beside `index.html`.

## Weather
Rain detection uses browser geolocation + Open-Meteo. If location/weather access is unavailable, the site simply remains in time-based mode.
